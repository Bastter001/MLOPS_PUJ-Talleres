# MLOPS_PUJ-Talleres

Repositorio académico que reúne los talleres desarrollados en la
asignatura de **Machine Learning Operations (MLOps)** de la Pontificia
Universidad Javeriana. El objetivo es aplicar buenas prácticas para el
desarrollo, despliegue y mantenimiento de soluciones de Machine Learning
en entornos reproducibles y escalables.

------------------------------------------------------------------------

## Objetivos

-   Aplicar principios fundamentales de MLOps.
-   Implementar flujos de entrenamiento y despliegue de modelos.
-   Gestionar dependencias y entornos de ejecución.
-   Utilizar herramientas de automatización y contenerización.
-   Fortalecer habilidades de desarrollo colaborativo mediante Git y
    GitHub.

------------------------------------------------------------------------

## Clonación del Repositorio

``` bash
git clone https://github.com/Bastter001/MLOPS_PUJ-Talleres.git
cd MLOPS_PUJ-Talleres
```

------------------------------------------------------------------------

## Ejecución de un Taller

Ingresar al directorio del taller correspondiente:

``` bash
cd Taller_0
```

Instalar dependencias:

``` bash
pip install -r requirements.txt
```

Ejecutar los scripts indicados en la documentación específica del
taller.

------------------------------------------------------------------------

## Resultados de Aprendizaje

Al finalizar los talleres, el estudiante podrá:

-   Diseñar proyectos organizados de Machine Learning.
-   Automatizar procesos de entrenamiento y evaluación.
-   Desplegar modelos mediante servicios web.
-   Empaquetar aplicaciones utilizando contenedores Docker.
-   Aplicar buenas prácticas de versionamiento y reproducibilidad.
